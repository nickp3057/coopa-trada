Schwab makes you log in again every 7 days. The bot can only use Schwab while this says Connected or Expiring soon.

  1. Open the Schwab login page (opens a new tab). Log in and click Allow.
  2. Schwab then sends that tab to an address starting with . The page will say it can’t be reached or show a security warning. That is expected.
  3. Copy the whole address from that tab’s address bar, paste it here, and click Finish. Do this straight away: the code in it only lasts a short time.
